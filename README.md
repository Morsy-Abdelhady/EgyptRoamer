# Egypt Roamer

Affiliate-first travel publication about Egypt: editorial content, comparison and decision support, and tracked links to booking partners. The site itself takes no bookings and no payments.

| Folder | What it is |
|---|---|
| `Egypt Roamer/` | The approved static prototype (design reference, not deployed) |
| `wordpress/wp-content/plugins/egypt-roamer-core/` | Business logic: content types, affiliate providers/offers, `/go/` redirects, click tracking and reports, leads, SEO guards, analytics events |
| `wordpress/wp-content/themes/egypt-roamer/` | The approved design as a WordPress theme |
| `tools/` | Bundler, seed export, translation build, QA scripts |
