# Content refresh

1. Start from a `seo-page-audit` section (or run it). Choose pages by evidence: impressions with low CTR, or
   position 4–20.
2. **Never change the URL or slug.** If one must change, stop and ask the owner (a redirect is needed).
3. Title and description: lead with the words people actually search; keep every fact true.
4. Add only sourced sections that answer real queries. Re-check time-sensitive facts (visa rules, hours, prices) on
   the official source, or remove them; update the "Last checked" date.
5. The English hash changes, so update all 7 translations and their review lines (see `content-writing`).
6. Add internal links to and from related pages and the matching comparison or experience page.
7. Release as in `content-writing`. Add a row to `growth/content/published-content.csv` (action `refresh`) with the
   date, so a later weekly review can compare before and after over periods of the same length.
