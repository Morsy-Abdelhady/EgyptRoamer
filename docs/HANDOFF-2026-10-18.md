## 4. How to work here (learned this session)
- **Local site:**
  - `python proxy.py` in `C:\Users\morsy\er` (port 8080, 6 PHP workers).
  - If pages hang, a worker is stuck: stop the proxy and its `php.exe` children (PowerShell `Get-CimInstance Win32_Process`), then start the proxy again.
  - Local trips have **no offers**, so test booking parts on production.
- **Playwright:** `playwright-core` with `channel:"chrome"`. For `tools/qa/page-coverage.mjs`, copy it with `import ... from "playwright-core"` (the repo file imports `playwright`).
- **Git Bash:** prefix fetch tests with `MSYS_NO_PATHCONV=1` (it rewrites `/paths`).
- **Deploy:**
  - Pushing to `main` deploys; poll `style.css` Version until it changes (about 2 minutes).
  - Then flush the GoDaddy cache in wp-admin through Claude in Chrome: `document.querySelector('#wp-admin-bar-wpaas-flush-cache a').click()`.
  - Then run page-coverage (about 10 minutes, 344 pages). A one-off `ERR_ABORTED` while the cache flushes: run it again.
- **Builds:** `PYTHONUTF8=1 python tools/build.py theme` after `src/js` changes.
- **Line endings:** write files with LF (`newline="\n"`). In Python edits, `\t` indentation differs from what Read shows; check with `cat -A` when an exact match fails.
