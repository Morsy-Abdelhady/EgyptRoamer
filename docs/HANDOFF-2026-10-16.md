## 6. Tooling notes (Windows quirks found today)

**Python builds** need `PYTHONUTF8=1`. Without it, `tools/build.py` and `tools/build-translations.mjs` (which calls Python) crash on Arabic text.

**UI strings** must be literal `er_t( '…' )` calls. `tools/i18n-strings.py` only collects literals, so a string passed through a variable ships untranslated.
- Add new strings to `tools/i18n/new-strings.json` in the order de, fr, it, es, ru, zh, ar.
- Then run `node tools/build-translations.mjs` and `python3 tools/build.py theme`.

**New offers** need card text in `plugins/egypt-roamer-core/data/offers-i18n.json` first, or the QA fails on untranslated titles. Partner-stated facts go in `data/offer-facts.json`; never add a fact the partner page does not state.

**HTTP checks.** Git Bash `curl` fails with SSL errors (exit 60). Use PowerShell `curl.exe` or `node -e "fetch(…)"`.
- Check offer redirects without counting a click: `curl.exe -A "curl/8" "https://egyptroamer.com/wp-admin/admin-post.php?action=er_go&offer=<slug>&pl=…"`.
- PowerShell scripts (`.ps1`) are blocked by the execution policy. Don't change it.

**Waiting for a deploy:**
```bash
until node -e "fetch('<url>').then(r=>r.text()).then(t=>process.exit(t.includes('<marker>')?0:1))"; do sleep 15; done
```
Run it through Monitor.

**After every deploy:**
- Flush the GoDaddy cache: wp-admin admin bar → `#wp-admin-bar-wpaas-flush-cache a`.
- Then run the QA:
  ```bash
  BASE=https://egyptroamer.com MSYS_NO_PATHCONV=1 node tools/qa/page-coverage.mjs
  ```
  - `tools/qa` imports `playwright`; a working copy that uses `playwright-core` was used in the old session's scratchpad.
  - The QA does not check the `?ux=2` preview or hotel boxes. Check those in the browser.

**Built-in browser.**
- A hidden Browser pane does not run IntersectionObservers; show the pane before measuring.
- Emulated widths above the pane width are scaled down in screenshots; use 1210px to read the sidebar.

**Unsplash.**
